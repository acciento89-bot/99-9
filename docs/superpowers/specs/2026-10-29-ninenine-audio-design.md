# NineNine original audio

Owner-authorized scope: quiet original music, ordinary UI/result effects, separate persistent switches in normal Settings, Android 1.2.0 (8). The old unpublished code-7 candidate and its QA evidence remain historical. No provider, signing, native export, device, or iOS work is part of this change.

Use checked-in, deterministic 22,050 Hz mono PCM16 WAVs generated by a Python standard-library script. A restrained 24-second sine/soft-harmonic composition and three short enveloped effects require no samples, artists, remote services, runtime synthesis, or downloaded music. Both loop ends are silent with smooth envelopes. A provenance JSON binds every output and its generator; a plain notice states actual procedural authorship without claiming a third-party licence.

One scene-owned audio service has one looping music player and two bounded non-overlapping effect players (UI and outcome). Music defaults on at a quiet level; effects default on. A separate `user://audio-v1.cfg` stores booleans, leaving existing profile/archive schemas untouched. Failed writes roll back and show an honest unsaved status. Music switch changes fade; background/focus loss pauses music, discards short effects, and never starts duplicate players. Foreground can resume music; gameplay requires its existing explicit Resume action.

An active `main_audio.gd` subclass preserves the existing practice/classic chain. It connects normal button feedback, classic result feedback, and only successfully persisted new practice results. The original Settings cards and their callbacks are moved intact into a touch-scroll area under the fixed Back/header; the audio card is first. No timing-screen controls move. English Settings matches the existing app; Practice retains its existing DE/EN policy.

Validation: generator reproducibility/PCM bounds/seams/envelopes; isolated headless actual service and UI with inert providers, persistence/failure/background/repeated notifications, classic and practice timing holds, result effects and no repeated persisted outcome, control reachability. No Editor import is allowed in this slice; any raw-font fixture adaptation is recorded explicitly. CPU metadata tests must reject stale code 7 and preserve iOS/project hashes. Root source review precedes any cloud build, hearing/native validation, or delivery.
